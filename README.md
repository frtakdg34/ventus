# Ventus

Ventus giyim ve epoksi ürünleri mağaza tasarımı. UstaRota ayrı bir depodadır.

Mağaza: https://frtakdg34.github.io/ventus/
UstaRota: https://frtakdg34.github.io/ustarota/

GitHub Pages main / (root) üzerinden yayınlanır. Bu sürüm tasarım önizlemesidir; gerçek üyelik, ödeme ve sipariş altyapısı henüz bağlı değildir.

Ürün düzenlemeleri app.js içinde, görünüm style.css içindedir. Görseller assets/ klasöründedir. Gizli anahtarlar, müşteri verileri ve kart bilgileri bu herkese açık depoya eklenmemelidir.

Eski /ventus/magaza/ bağlantısı mağaza ana sayfasına yönlendirilir.
